ממתינות בתור

לפני שמפעילים: מפתח של Google Gemini

  1. נכנסים ל־aistudio.google.com/apikey עם חשבון Google, ולוחצים Create API key.
  2. מחברים אמצעי תשלום (Billing) לפרויקט של המפתח. בלי זה יש מגבלות שימוש נמוכות.
  3. מעתיקים את המפתח. ב־Render: Environment ← Add variable, ב־KEY כותבים GEMINI_API_KEY וב־VALUE מדביקים את המפתח, ואז Save, rebuild, and deploy.
  4. חוזרים לעמוד הזה. המצב "מפתח Gemini" יתחלף ל"מחובר".
