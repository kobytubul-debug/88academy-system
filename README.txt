88ACADEMY — מערכת הסטודנטים (גרסת שרת)
=========================================

מה יש כאן
- server.js, model.js, ai.js — השרת (ai.js: בדיקת סרטונים עם Google Gemini). בלי תלויות חיצוניות (רק Node 20 ומעלה).
- package.json — פקודת ההפעלה: npm start
- public/ — כל המסכים (סטודנט, מנהל, משקיף).

הגדרות ב־Render (Web Service)
- Build Command:  npm install
- Start Command:  npm start
- Environment Variables:
    NODE_VERSION    = 22.13.0
    NODE_ENV        = production
    DATA_DIR        = /data
    ADMIN_USERNAME  = שם המשתמש של המנהל הראשי (באנגלית)
    ADMIN_PASSWORD  = סיסמה חזקה למנהל הראשי
- Disk: Mount Path = /data, גודל 1GB. כל הנתונים נשמרים בקובץ אחד: /data/academy.json
  בלי Disk הנתונים נמחקים בכל עדכון של האתר.

אחרי שהאתר עולה
1. נכנסים עם ADMIN_USERNAME ו־ADMIN_PASSWORD.
2. יחידות: מגדירים את הקבוצות.
3. סטודנטים: יוצרים חשבון לכל סטודנט ומשקיף, עם סיסמה זמנית.
   בכניסה הראשונה כל אחד בוחר סיסמה משלו. מנהל יכול לאפס סיסמה בכרטיס הסטודנט.
4. משקיף רואה רק את הקבוצה שהוא משויך אליה, לקריאה בלבד.

איך זה עובד
- סרטוני טיסה שהסטודנטים מעלים נמחקים אוטומטית כמה ימים אחרי שבדקתם אותם (ברירת מחדל 14, משנים בתחתית עמוד תוכנית הלימודים). הסטטוס, המשוב והמטבעות נשארים.
- תוכנית לימודים: מוסיפים, עורכים, מסדרים, משביתים ומוחקים רמות ומיומנויות (שם, תיאור, איך עוברים, מפה, נקודות, סרטון הדגמה: קובץ מהמחשב עד 500MB או קישור).
- סרטונים שמעלים נשמרים ב־Disk (בתיקייה /data/media). Disk של 1GB מספיק לכמה סרטונים קצרים; להרבה סרטונים מגדילים אותו ב־Render (Disk ← Size). מיומנות לא פעילה מוסתרת מהסטודנטים ולא נדרשת לסיום הרמה.
- אתגרים: מוסיפים אתגר עם נקודות, רמה ותאריך סיום. סטודנט מגיש טיסה לאתגר, ואתם מאשרים בכרטיס הסטודנט.
- פרסים: כותרת, תיאור, מחיר, מלאי, תמונה שמעלים מהמחשב, קישור שנשלח למי שקיבל את הפרס, ושיוך לקבוצות.
- כל משתמש יכול להחליף סיסמה (כפתור המפתח בראש המסך, או בתפריט האישי של הסטודנט).
- סטודנט מגיש טיסה בהעלאת סרטון מהטלפון (עד 200MB) או בקישור (YouTube לא רשום או Google Drive). המנהל רואה אותה בכרטיס הסטודנט ובעמוד הסקירה, ומאשר או מחזיר עם הערה.
- מטבעות על כניסה יומית, רצף, זמן למידה וסרטונים נבדקים בשרת, כך שאי אפשר לזייף אותם.
- בקשות לפרסים מופיעות בעמוד הפרסים: "נמסר" או "דחייה והחזרת המטבעות".
- בדיקת AI של סרטונים: לא פעילה בגרסה הזו. כל טיסה נבדקת על ידי המדריך.
- מסך משחק לתלמידים: בעמוד הקורסים בוחרים קבוצה, ובחלק "המסך של התלמידים" בוחרים את המסך הרגיל או משחק
  באחת מערכות הנושא (מירוץ, צבעוני, צבאי, או ערכה שעיצבתם בעמוד העיצוב). ברירת המחדל היא המסך הרגיל.
  ההתקדמות, המטבעות, הטיסות והפרסים זהים בשני המסכים. כל תלמיד רואה רק את המסך שנבחר לקבוצה שלו.
- המשחק (public/Game.html): כל רמה היא עולם, כל מיומנות היא חלון, בסוף כל רמה תיבה עם בונוס סיום הרמה,
  והמבחן המסכם הוא הגמר. ליגת השבוע מראה את המטבעות שכל שחקן בקבוצה צבר מיום ראשון: רק מי שצובר נקודות,
  בשם פרטי ואות ראשונה של שם המשפחה. סטודנט שלא צובר נקודות רואה את אותו מסלול בלי מטבעות, ליגה ופרסים.
- הרחפן של התלמיד במשחק (בהאנגר ועל המסלול): רחפן הקורס בשלוש גרסאות. הראשונה פתוחה מההתחלה, ועוד אחת
  נפתחת בסיום כל רמה. היציאה מהחשבון נמצאת בתפריט של המשחק, מתחת להאנגר, ושואלת לפני שיוצאים.
- מגדל הפיקוח (תפריט המנהל → מגדל הפיקוח, public/Tower.html): כל הטיסות שמחכות לבדיקה בתור אחד, הוותיקה למעלה,
  עם סינון לפי קבוצה. צופים בסרטון, מדרגים 1–3 כוכבים, כותבים הערה, ומאשרים או מחזירים לתיקון (בהחזרה ההערה חובה).
  הכוכבים מופיעים לתלמיד על התרגיל ובהודעה; הם לא משנים את מספר המטבעות.
- עיצוב האתר (תפריט המנהל → עיצוב האתר, public/Studio.html), עם תצוגה מקדימה חיה של המשחק:
  · ערכות נושא: סגנון בסיס, יום/לילה, צבעים, גופנים, אייקונים, רקע (גם תמונה מהמחשב), מילים, תנועה,
    ושיוך כל קבוצה לערכה או למסך הרגיל. שלוש הערכות המובנות אפשר לערוך ולאפס, לא למחוק.
  · רקע לשלב: רקע לכל רמה, תרגיל, תיבה והמבחן המסכם. רקעים משותפים לכל הקבוצות.
  התלמידים רואים את השינוי אחרי שמירה (משחק פתוח מתעדכן תוך חצי דקה).
- בעמוד הקורסים, בכל קבוצה: "צבירת נקודות בקבוצה" (כולם צוברים / אף אחד) ו"פרסים לקבוצה".
- כדאי להוריד מדי פעם את /data/academy.json (ב־Render: Shell → cat /data/academy.json).

הרצה מקומית לבדיקה
  node server.js
  ואז http://localhost:3000 (משתמש: admin, סיסמה: admin1234 — רק כשאין NODE_ENV=production)
