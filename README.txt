88ACADEMY — מערכת הסטודנטים (גרסת שרת)
=========================================

מה יש כאן
- server.js, model.js — השרת. בלי תלויות חיצוניות (רק Node 20 ומעלה).
- package.json — פקודת ההפעלה: npm start
- public/ — כל המסכים (סטודנט, מנהל, משקיף).

הגדרות ב־Render (Web Service)
- Build Command:  npm install
- Start Command:  npm start
- Environment Variables:
    NODE_VERSION    = 22.13.0
    NODE_ENV        = production
    DATA_DIR        = /data
    ADMIN_USERNAME  = שם המשתמש של המנהל הראשי (באנגלית)
    ADMIN_PASSWORD  = סיסמה חזקה למנהל הראשי
- Disk: Mount Path = /data, גודל 1GB. כל הנתונים נשמרים בקובץ אחד: /data/academy.json
  בלי Disk הנתונים נמחקים בכל עדכון של האתר.

אחרי שהאתר עולה
1. נכנסים עם ADMIN_USERNAME ו־ADMIN_PASSWORD.
2. יחידות: מגדירים את הקבוצות.
3. סטודנטים: יוצרים חשבון לכל סטודנט ומשקיף, עם סיסמה זמנית.
   בכניסה הראשונה כל אחד בוחר סיסמה משלו. מנהל יכול לאפס סיסמה בכרטיס הסטודנט.
4. משקיף רואה רק את הקבוצה שהוא משויך אליה, לקריאה בלבד.

איך זה עובד
- תוכנית לימודים: מוסיפים, עורכים, מסדרים, משביתים ומוחקים רמות ומיומנויות (שם, תיאור, איך עוברים, מפה, נקודות, סרטון הדגמה כקישור). מיומנות לא פעילה מוסתרת מהסטודנטים ולא נדרשת לסיום הרמה.
- אתגרים: מוסיפים אתגר עם נקודות, רמה ותאריך סיום. סטודנט מגיש טיסה לאתגר, ואתם מאשרים בכרטיס הסטודנט.
- פרסים: כותרת, תיאור, מחיר, מלאי, תמונה (קישור) או סמל, קישור שנשלח למי שקיבל את הפרס, ושיוך לקבוצות.
- כל משתמש יכול להחליף סיסמה (כפתור המפתח בראש המסך, או בתפריט האישי של הסטודנט).
- סטודנט מגיש טיסה כקישור (YouTube לא רשום או Google Drive). המנהל רואה אותה בכרטיס הסטודנט ובעמוד הסקירה, ומאשר או מחזיר עם הערה.
- מטבעות על כניסה יומית, רצף, זמן למידה וסרטונים נבדקים בשרת, כך שאי אפשר לזייף אותם.
- בקשות לפרסים מופיעות בעמוד הפרסים: "נמסר" או "דחייה והחזרת המטבעות".
- בדיקות AI כבויות בגרסה הזו; כל טיסה נבדקת ידנית.

גיבוי
- כדאי להוריד מדי פעם את /data/academy.json (ב־Render: Shell → cat /data/academy.json).

הרצה מקומית לבדיקה
  node server.js
  ואז http://localhost:3000 (משתמש: admin, סיסמה: admin1234 — רק כשאין NODE_ENV=production)
