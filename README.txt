88ACADEMY - FPV NEXUS, סימולטור טיסה (גרסת שרת)
================================================

מה יש כאן
- server.js: שרת Node קטן בלי תלויות (Node 20 ומעלה). מגיש את המשחק ושומר את כל הנתונים בקובץ אחד.
- public/index.html: המשחק עצמו. public/import.html: דף חד-פעמי לייבוא נתונים קיימים.
- package.json: פקודת ההפעלה npm start.

הגדרות ב-Render (Web Service) - אותן הגדרות כמו במערכת הקודמת
- Build Command: npm install
- Start Command: npm start
- Environment Variables:
    NODE_VERSION    = 22.13.0
    NODE_ENV        = production
    DATA_DIR        = /data
    ADMIN_USERNAME  = שם המשתמש של המנהל
    ADMIN_PASSWORD  = סיסמה חזקה למנהל
- Disk: Mount Path = /data. הנתונים נשמרים ב-/data/nexus.json. בלי Disk הם נמחקים בכל עדכון.

שימוש
- מנהל: במסך הכניסה לוחצים "כניסת מנהל" (מתחת לטופס הכניסה של התלמיד) ומזינים ADMIN_USERNAME ו-ADMIN_PASSWORD.
  אחר כך כל הניהול נעשה מתוך המשחק: קבוצות, שחקנים, מסלולים, קורסים, מעקב ודוחות.
- תלמידים ומדריכים: נכנסים עם שם המשתמש והסיסמה שהמנהל יצר להם, בלי חשבון נוסף.
- גיבוי: בלשונית "שחקנים", כרטיס "גיבוי וייצוא נתונים" שומר קובץ JSON עם כל הנתונים.
- ייבוא: פותחים /import, מזינים פרטי מנהל ובוחרים קובץ ייצוא. כך מעבירים נתונים מגרסת Claude או משחזרים גיבוי.

הרשאות בשרת
- כתיבה: רק המנהל, חוץ ממה שכל שחקן כותב על עצמו (players, hist, live).
- סיסמאות: ה-hash אינו נשלח לדפדפן. הבדיקה נעשית בשרת, עם הגבלת נסיונות.
- מיקומי טיסה חיים (live) נראים רק למנהל ואינם נשמרים בדיסק.

המערכת הקודמת (ניהול סטודנטים) שמורה בענף backup-student-system-2026-11-08.
